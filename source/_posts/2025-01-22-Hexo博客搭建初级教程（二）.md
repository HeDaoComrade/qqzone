# 从零开始搭建Hexo博客

------
<div style="background-color: #87cefa; padding: 10px; border-radius: 5px; color: #333;">作者：HeDaoZhiWan(Miaplacidus)</h1></div>

------

## 本篇：初始化博客
### 上一篇：环境搭建

------

#### 1. 创建Hexo项目

1. 在我们之前创建的博客文件夹中右键，Git Bash here并键入：

   ```bash
   mkdir HexoBlog
   cd HexoBlog
   ```

2. 初始化Hexo：

   ```bash
   hexo init
   npm install
   ```

#### 2. 启动本地服务

1. 启动Hexo本地服务：

   ```bash
   hexo server
   ```
<div style="background-color: #ffcc00; padding: 10px; border-radius: 5px; color: #333;">注意：除本处本次之外，以后的步骤都必须使用三件套：</div>

	hexo clean; hexo g; hexo d（或者hexo s，看你需要什么，但前两步必须有）

2. 打开浏览器访问`http://localhost:4000`，即可看到默认博客页面。

### 更换主题

#### 1. 下载主题

<div style="background-color: #ffcc00; padding: 10px; border-radius: 5px; color: #333;">关于主题的自定义与魔改会在后面的章节具体阐述，在这里介绍基本标准主题</div>

1. 找到喜欢的主题：[Hexo主题仓库](https://hexo.io/themes/)。

2. 下载主题，例如NexT：

   ```bash
   git clone https://github.com/hexo-theme-next/hexo-theme-next themes/next
   ```

#### 2. 配置

1. 修改 _config.yml 文件（站点配置文件）中的 ` theme `值：
   ```yaml
   theme: next
   ```
   
2. 博客的信息个性化
	修改站点配置文件_config.yml，默认语言是 en 。
	以butterfly主题为例，它支持三种语言：

+ default(en)
+ zh-CN (简体中文)
+ zh-TW (繁体中文)
  
   修改网站各种资料，例如标题、副标题和邮箱等个人资料，请修改站点配置文件_config.yml。部分参数如下，详细参数可参考官方的配置描述。

| 参数        | 描述                                                         |
| ----------- | ------------------------------------------------------------ |
| title       | 网站标题                                                     |
| subtitle    | 描述                                                         |
| description | 网站描述                                                     |
| keywords    | 网站的关键词。支持多个关键词                                 |
| author      | 网站开发者（也就是你）的名字                                 |
| language    | 网站使用的语言。对于简体中文用户来说，使用不同的主题可能需要设置成不同的值，请参考你的主题的文档自行设置，常见的有 zh-Hans 和 zh-CN。 |
| timezone    | 网站时区。Hexo 默认使用您电脑的时区。请参考时区列表进行设置，如 America/New_York, Japan, 和 UTC。一般的，对于中国大陆地区可以使用 Asia/Shanghai |


#### 3. 生成和启动服务

1. 重新生成并启动服务查看效果：

   ```bash
   hexo clean
   hexo g
   hexo s
   ```

------
